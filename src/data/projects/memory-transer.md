### やったこと

BitSummit Game Jam 2023で制作しました。初対面のメンバーと取り組んだ初めての外部ゲームジャムで、自らリードエンジニアに立候補しました。

制作開始時には、他のプログラマー向けにGitやRiderの講習を行い、プログラム全体の設計、タスク分割・割り振りまで担当しました。

### 課題と対応

制作途中からメンバーの離脱が相次ぎ、プログラマーも実質的に自分一人で実装を進める必要がある状況になりました。

そこで、まず「必要であればプログラムは自分一人でも書き切る」と決め、実装を進めました。一方で、コードを書くだけではゲームは完成しないため、企画や仕様の未決定事項を解消するための集会を自ら複数回開催しました。

残ったプランナー・デザイナーと、その場で未決定事項を整理して意思決定を行い、必要な機能へ実装を集中することで、最終的に作品を完成させました。

### 学んだこと

この制作では、リードエンジニアの役割は単に技術的な判断をすることではなく、作品を完成させるために必要であれば意思決定の場そのものを作ることだと学びました。

実装とチーム進行の双方から制作を立て直した経験として、その後のリーダー・マネジメント経験の基礎になっています。
