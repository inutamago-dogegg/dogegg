### 作品の詳細

『Memory Transer』は、記憶を整理することをテーマにしたアクションゲームです。BitSummit Game Jam 2023で制作しました。

限られた制作期間の中で、アクションとして遊べる形と、記憶を扱う作品テーマを一つのゲームとしてまとめています。

### 担当

リードエンジニアとして、プログラム全体の設計、実装、タスク分割・割り振りを担当しました。制作開始時には、他のプログラマー向けにGitやRiderの講習も行いました。

### 開発について

制作途中からメンバーの離脱が相次ぎ、プログラマーも実質的に自分一人で実装を進める必要がある状況になりました。

実装を引き取るだけでは作品を完成させられないため、企画や仕様の未決定事項を解消するための集会を自ら複数回開催し、残ったメンバーとその場で意思決定を進めました。

必要な機能へ実装を集中することで作品を完成させ、リードエンジニアには技術判断だけでなく、制作を前へ進めるための意思決定の場を作る役割もあると学びました。
